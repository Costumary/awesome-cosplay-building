# Contributing to Awesome Cosplay Building

Thanks for wanting to help make this list better. Contributions from builders who actually use these materials and tools are what make this resource useful.

## What belongs here

- Materials, tools, suppliers, and techniques you have personally used or seen used in real builds
- Honest opinions: if something is overpriced, say so. If there's a cheaper alternative, list it
- Resources that help people actually build costumes, not just browse

## What doesn't belong

- Products you haven't used or can't vouch for
- Generic craft supplies with no cosplay-specific context
- Duplicates of items already listed

## How to contribute

1. Fork this repository
2. Create a branch (`git checkout -b add-thermoplastic-section`)
3. Make your changes to `README.md`
4. Make sure your addition follows the existing format:
   - `[Item Name](link)` followed by a description with real pricing and honest opinions
   - Place it in the correct section
   - Use the same tone as existing entries
5. Submit a pull request

## Format

Each entry should look like this:

```markdown
- [Product or Resource Name](https://example.com) - What it is, what it costs, and why a builder would care. Be specific.
```

Keep descriptions to one or two sentences. If you need more space, the item might deserve its own subsection.

## Updating existing entries

If a price changed, a link broke, or a product got discontinued, please submit a PR to fix it. Keeping this list accurate matters more than keeping it long.

## Code of conduct

Be helpful, be honest, be kind. This is a community resource for people who build costumes. Keep it that way.
